# ch_03_01_요약.ipynb — 문서 요약 (Summarization)

LangChain으로 문서를 요약하는 다양한 기법을 다루는 튜토리얼입니다.

## 다루는 기법

- **Stuff**: 전체 문서를 한 번에 프롬프트에 넣어 요약. 문서가 작고 호출당 몇 개만 전달되는 경우에 적합.
- **Map-Reduce**: 문서를 청크로 나눠 각각 요약(map) 후, 요약들을 하나로 병합(reduce). 긴 문서 처리와 토큰 제한 우회에 유리.
- **Map-Refine**: 각 청크를 순차적으로 처리하며 이전 요약을 점진적으로 개선(refine)하는 방식.
- **Chain of Density**: 동일 프롬프트를 N회 반복 실행하며 누락된 entity를 보완해 요약을 점점 밀도 있게 개선. (참고: https://arxiv.org/pdf/2309.04269)
- **Clustering-Map-Refine**: 문서 청크를 N개의 클러스터로 나눈 뒤, 각 클러스터의 중심에 가까운 문서만 뽑아 Refine 방식으로 요약 (gkamradt 튜토리얼 참고).

## 주요 사용 API

- `TextLoader`, `PyPDFLoader` (`langchain_community.document_loaders`) — 뉴스 텍스트/PDF 로드
- `client.pull_prompt(...)` (`langsmith.Client`) — teddynote가 공개한 요약 프롬프트들(`summary-stuff-documents-korean`, `map-prompt`, `reduce-prompt`, `map-summary-prompt`, `refine-prompt`, `chain-of-density-prompt`) 다운로드
- `create_stuff_documents_chain` (`langchain_classic.chains.combine_documents`)
- `ChatOpenAI`, `StreamingCallback` — 스트리밍 출력
- `KMeans` (`sklearn`) — Clustering-Map-Refine 단계에서 청크 클러스터링
