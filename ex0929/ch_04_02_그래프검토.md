# ch_04_02_그래프검토.ipynb — Runnables 구조 검토

LCEL로 만든 `runnable` 체인의 내부 구조를 시각적으로 검사하는 방법을 다루는 튜토리얼입니다.

## 핵심 개념

- `chain.get_graph()` — 체인의 실행 구조를 그래프 객체로 변환
- `graph.print_ascii()` — 그래프를 아스키 다이어그램으로 출력해 체인의 흐름을 한눈에 파악 (내부적으로 `grandalf` 패키지 필요)

## 예제

- FAISS 검색기 + 프롬프트 + `ChatOpenAI` + `StrOutputParser`로 구성한 RAG 체인을 만든 뒤, 그 구조를 그래프로 확인

## 주요 사용 API

- `langchain_core.prompts.ChatPromptTemplate`
- `langchain_community.vectorstores.FAISS`
- `langchain_core.runnables.RunnableLambda`, `RunnablePassthrough`

## 필요 패키지

- `faiss-cpu`, `tiktoken`, `grandalf` (그래프 렌더링용)
