# ch_04_06_런타임체인구성.ipynb — 런타임에 체인 내부 구성하기

체인을 호출(invoke)할 때 다양한 옵션을 동적으로 설정하는 방법을 다루는 튜토리얼입니다.

## 두 가지 동적 구성 방식

- **configurable_fields**: 실행 가능한 객체(Runnable)의 특정 필드를 구성 가능하게 만듦.
  예) `ChatOpenAI`의 `model_name`을 고정하지 않고 `ConfigurableField`로 감싸서 호출 시점에 동적으로 모델을 바꿀 수 있게 설정.
- **configurable_alternatives**: 런타임 중에 Runnable 객체 자체를 통째로 다른 대안으로 교체 가능하게 나열.
  예) `HubRunnable`로 LangChain Hub에 등록된 프롬프트를 런타임에 교체.

## 주요 사용 API

- `langchain_core.runnables.ConfigurableField`
- `langchain_core.prompts.PromptTemplate`
- `ChatOpenAI(temperature=0, model_name="gpt-4o")`
